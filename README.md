# Face Recognition System using OpenCV

## Project Overview
This project focuses on developing a real-time face detection and recognition system using Python and OpenCV.

## Technologies Used
- Python 3.12
- OpenCV
- NumPy
- Haar Cascade Classifier
- Principal Component Analysis (PCA)

## Project Objectives
- Detect human faces using a webcam.
- Collect and process facial image datasets.
- Implement PCA for facial feature representation.
- Recognize registered faces using distance-based matching.
- Display real-time face detection and recognition results.
